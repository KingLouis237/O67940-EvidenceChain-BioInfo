# Sequence alignment outputs

This folder contains MAFFT alignments and alignment summaries used in the O67940_AQUAE evidence chain.

## Reviewed Swiss-Prot reference alignment

`O67940_reviewed_swissprot_reference_set_mafft_alignment.fasta` is the MAFFT alignment of the 14-sequence reviewed/reference set.

It contains:

- O67940_AQUAE
- 2Q6O chain A
- 1RQP chain A
- 11 curated Swiss-Prot JackHMMER hits

This alignment is used as a controlled reference layer for later residue conservation and mapping. It is not the final broad homolog alignment.
