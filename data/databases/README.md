# Local sequence databases

This folder stores local searchable databases used for the publication-upgrade analyses.

Large database files are not committed to Git.

For each database, record:

- source URL;
- access date;
- local path;
- checksum;
- purpose.

Records should be kept in:

- metadata/source_provenance.tsv
- metadata/checksums_sha256.txt
- notes/workflow_log.md
